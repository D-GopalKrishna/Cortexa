# Connectomics

Graph tools and QA over traced circuits — natural extension of NeuroGlass-style annotation work.

## Projects

| Project | Data | Why it matters |
|---------|------|----------------|
| [Graph-theoretic analysis](graph-theoretic-analysis/) | C. elegans (or similar) | Small, fully mapped; fast results |
| [Tracing QA tool](tracing-qa-tool/) | Synthetic or public traces | Direct NeuroGlass narrative |
| [FlyWire circuit explorer](flywire-circuit-explorer/) | FlyWire subset | Query / hop exploration at scale |
| [Connectome comparison viewer](connectome-comparison-viewer/) | Two versions of a circuit | Annotator agreement / QA diffs |

## Shared skills to practice

- NetworkX / graph-tool basics
- Centrality, modularity, motifs, path queries
- Visualization of large sparse graphs
- Error heuristics: orphans, disconnects, degree outliers
