# Computational Neuroscience

Models from single-neuron biophysics up to network and mass dynamics. Goal: show you understand the math and can simulate + visualize behavior.

## Projects

| Project | Tooling | Why it matters |
|---------|---------|----------------|
| [Hodgkin–Huxley model](hodgkin-huxley-model/) ⭐ starter | NumPy / SciPy from scratch | Equations-level credibility |
| [Spiking neural network](spiking-neural-network/) | Brian2 or NEST | Emergent network phenomena |
| [Reservoir computing](reservoir-computing/) | NumPy (+ optional Brian2) | Bridges ML and comp-neuro |
| [Neural mass EEG rhythms](neural-mass-eeg-rhythms/) | NumPy / SciPy | Link models to real EEG bands |

## Shared skills to practice

- ODEs, phase plots, parameter sweeps
- Spike trains, raster plots, synchrony metrics
- Relating model spectra to delta / theta / alpha / beta / gamma
