# Spiking Neural Network Simulation

Build a small network in Brian2 (or NEST), tune connectivity, and visualize emergent firing (synchrony, oscillations, waves).

## Suggested stack

- Brian2 (recommended for learning speed) or NEST
- NumPy / Matplotlib for analysis

## Milestones

1. Single LIF / AdEx neuron; then a small E/I population
2. Raster plots + population rate over time
3. Sweep connectivity / inhibition; find sync vs. asynchrony regimes
4. Quantify synchrony (e.g. pairwise correlation, Kuramoto order if phases available)
