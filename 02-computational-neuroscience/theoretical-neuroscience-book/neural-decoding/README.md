# Ch3 — Neural decoding

Recovering stimulus/intent from neural responses — population vector
decoding, Bayesian decoding (MAP/ML estimators), and the accuracy limits set
by neural variability.

## Relevance

This is the theory behind every classifier in
[03-bci-signal-processing](../../../03-bci-signal-processing/) (focus/attention,
SSVEP, P300) — those projects build decoders empirically; this chapter is
where the Bayesian/optimal-decoder framing they're implicitly approximating
comes from.
