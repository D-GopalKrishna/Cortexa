# Ch2 — Neural encoding II: reverse correlation and receptive fields

How a neuron's response relates to a stimulus — spike-triggered average,
linear response models, and receptive field estimation (classically for
visual neurons, but the reverse-correlation method generalizes).

## Relevance

Least directly used elsewhere in this repo (no visual-neuron project here),
but the reverse-correlation method is the same idea behind estimating which
features of an EEG signal (or any timeseries) a downstream classifier is
actually keying on — worth reading for the method, not the visual-system
specifics.
